## 🛠️ 如何彻底消除“未知发布者”警告？

### 步骤 1：在目标机/测试机导入证书
1. 将 `HaiwenNa-CodeSigning.cer` 和 `一键安装海文娜AI受信任证书.bat` 拷贝到测试机。
2. 双击运行 `一键安装海文娜AI受信任证书.bat`（会自动提示请求管理员权限）。
3. 提示“海文娜AI 证书已成功安装至此计算机”即表示就绪。

### 步骤 2：验证效果
- 双击运行已签名的 `ChildGuard-Setup.exe` 或 `Haidou.ChildGuard.Wpf.exe`；
- Windows 弹窗上的发行商将正式显示为：**“海文娜AI”**；
- 下方的红色“此文件没有包含有效的数字签名”警告彻底消失！

## 🌐 关于网络社区与开源“免费受信任代码签名证书”的说明

### 1. 为什么代码签名没有像 Let's Encrypt（免费 HTTPS）那样的完全免费公共 CA？
- HTTPS 证书仅验证网站域名控制权，全流程自动化，零人工成本。
- Windows 代码签名（Code Signing）拥有在用户电脑上执行任意本地机器码的高危权限。微软与国际 CA/B 论坛规定：
  - 必须进行严格的人工实体身份核验（营业执照、身份证公证、律师信、电话核验等）；
  - **2023年行业强制新规**：私钥必须存储在硬件 USB 智能卡（Token）或云端合规 HSM 硬件中，不得导出普通软证书文件，存在不可避免的硬件与运营成本。因此商业 CA（DigiCert、Sectigo 等）年费通常在 2000~4000 元。

### 2. 网络社区/开源项目推荐的免费与低成本正规方案

1. **SignPath Foundation 开源计划（纯免费、全球权威信任）**：
   - 官网：[https://signpath.org/](https://signpath.org/)
   - 专为 GitHub 上的非商业开源项目提供免费云代码签名服务；
   - 原生支持 GitHub Actions 流水线，审核通过后每次打 Tag 发布即可自动在云端完成全球受信任签名。
2. **自签名证书 + 一键导入脚本（本项目内置方案，100% 免费）**：
   - 即本项目当前采用的方案。适合团队内部、测试机、小范围用户分发。
3. **Microsoft Store 微软应用商店通道（个人开发者 19 美元终身）**：
   - 一次性支付 19 美元注册微软开发者账号；
   - 应用上架后由微软官方服务器背书全球受信任签名，任何 Windows 电脑均不弹任何警告。
